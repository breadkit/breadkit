Three independent tools.

Use the shared core on its own, then add rendering or linting as needed. Each gem has its own repository and release cycle.

  • Circuit model

    breadkit

    Describe boards and parts, resolve wires into nets, and export circuit data.

    Open the core repository

  • Circuit drawings

    breadkit-render

    Render the same circuit as a deterministic SVG, with optional raster output.

    Open the renderer repository

  • Circuit checks

    breadkit-lint

    Catch wiring, layout, and electrical mistakes before building the circuit.

    Open the linter repository
