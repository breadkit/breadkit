Components and modules

Place a component by naming the holes for its leads or its anchor hole. Use offboard for modules beside the breadboard, then wire their named pins.

Common components

These built-in definitions support rendering and connection analysis. Hole positions are examples; choose positions that fit your circuit.

ComponentDSLPlacement
Resistorresistor :R1, "330", pins: %w[a12 a16]Two leads
LEDled :D1, color: :red, anode: "b16", cathode: "b17"Two polarized leads
Push buttonbutton :SW1, at: "e10"Across the center gap
Capacitorcapacitor :C1, "10n", pins: %w[h23 h24]Two nonpolarized leads
Electrolytic capacitorelectrolytic :C2, "100u", plus: "g22", minus: "j24"Positive and negative leads
NE555ic :U1, "NE555", at: "e20"Anchor at pin 1

Built-in definitions also include diodes, transistors, and potentiometers. BC547 and BC557 use CBE pin order; 2N3904 and 2N3906 use EBC. An unknown transistor model emits a warning and uses the generic EBC order. Run breadkit parts to list definitions. Values may use units such as 4.7k or 10uF.

Define module pins

Define offboard modules such as OLEDs and sensors in YAML. This excerpt from the SHT31 definition names each pin and its type:, which controls the pin marker color.

parts/sht31.yml
id: sht31
category: module
placement: offboard
pins:
  - {num: 1, name: VIN, type: power}
  - {num: 2, name: GND, type: ground}
  - {num: 3, name: SCL, type: clock}
  - {num: 4, name: SDA, type: data}
  - {num: 5, name: ADR, type: address}
  - {num: 6, name: ALR, type: interrupt}
render: {shape: offboard, label: SHT31}
Use it in a circuit file
board :full
use_parts "parts/*.yml"
offboard :SHT31, :sht31, side: :right,
         at: "a12", address: "0x44"

wire "SHT31.SCL", "h22", color: :yellow
wire "SHT31.SDA", "h24", color: :blue

The module appears beside the board. Wire SCL and SDA by name, and connect the real power pins too.

For a board-mounted module such as an RP2040, define placement: footprint and its pin positions, then place it with part :PICO, :rp2040_clone, at: "c1". Browse the part definitions.
